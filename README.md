# AI Shift Hackathon starter

Your own computer in the browser, with Claude Code ready to use.

## Get started

1. Sign in to GitHub.
2. At the top of this page, click **Use this template** > **Create a new repository**.
3. Name: `my-hackathon-project`. Choose **Public**. Click **Create repository**.
4. In your new repository, click **Code** > **Codespaces** > **Create codespace on main**.
5. Wait until it opens (1-3 minutes). If it asks for `OPENROUTER_API_KEY`, paste your key from the welcome email.
6. Follow `START-HERE.md`, which opens by itself.

Works in Chrome, Edge or Safari, on a laptop or on an iPad with a keyboard.
